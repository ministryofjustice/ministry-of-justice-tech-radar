Axe is an accessibility testing tool with the axe-core JavaScript engine and integrations for common test frameworks. Adopt it to catch accessibility issues early in development and automate repeatable checks in test suites and CI. Automated checks identify only some accessibility barriers, so combine them with manual testing against the relevant accessibility standard.
